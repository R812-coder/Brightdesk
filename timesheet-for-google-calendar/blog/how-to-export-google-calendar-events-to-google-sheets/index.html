How to Export Google Calendar Events to Google Sheets

Google Calendar has no built-in way to export events to a spreadsheet. Here are three methods — from manual to fully automated — ranked by effort and reliability.

Why you’d want to export calendar events

The most common reasons people search for this:

  • Billing — Turn meeting logs into timesheets for invoicing
  • Reporting — Analyze how time is spent across projects
  • Record keeping — Archive a permanent log of events for a date range
  • Payroll — Calculate hours worked for contractors
  • Project management — Review time allocation across team calendars

Google Calendar is great at displaying events visually, but it has no spreadsheet export. You have to get the data out yourself.

Method 1: ICS export (limited)

Google Calendar’s only native export is an .ics file. To get it: Settings → Import & export → Export. This downloads a ZIP containing .ics files for each calendar.

The problem: ICS is designed for transferring events between calendar apps, not for spreadsheets. The format looks like this:

BEGIN:VEVENT
DTSTART:20260324T140000Z
DTEND:20260324T153000Z
SUMMARY:Client Call
END:VEVENT

Why ICS doesn’t work for most use cases: Times are in UTC (not your local timezone), there’s no duration calculation, recurring events aren’t expanded into individual instances, and you’d need to parse the file manually to get it into a spreadsheet. For billing or reporting, this is effectively useless.

Method 2: Manual copy-paste

Open Google Calendar and a Google Sheet side by side. For each event in your date range:

  1. Click the event to see its details
  2. Type the date, start time, end time, and title into the spreadsheet
  3. Calculate duration with =(C2-B2)*24
  4. Repeat for every event

This is straightforward for a handful of events but becomes painful quickly. A typical work week has 15-25 events. A month has 60-100. And you still have to handle recurring events (weekly standups appear once in Calendar but should be 4-5 rows in your sheet), declined meetings, all-day events, and timezone edge cases.

Method 3: One-click with an add-on

The fastest method is a Google Sheets add-on that reads the Calendar API and writes directly to your spreadsheet. Timesheet for Google Calendar does this in one click.

  1. Install the add-on from the Google Workspace Marketplace
  2. Open any Google Sheet → Extensions → Timesheet for Google Calendar → Open Settings
  3. Select which calendars to include
  4. Choose a date range (This Week, Last Week, This Month, or custom)
  5. Click Generate Timesheet

The add-on creates a formatted spreadsheet with columns for Date, Day, Start, End, Event name, Hours, Project, Rate, and Amount. Recurring events are expanded into individual rows. All-day and declined events are automatically skipped. Times are in your local timezone.

What about Apps Script? You can also write a custom Apps Script to pull calendar events via the Calendar API. This gives you full control but requires JavaScript knowledge and ongoing maintenance. For most people, an add-on is faster and more reliable than maintaining custom code.

FAQ

Can I export just one calendar?

With ICS, you can export individual calendars. With the add-on, you select which calendars to include via checkboxes — you can pick one, several, or all.

Does the add-on access my calendar data?

It uses read-only access (calendar.readonly). It can never create, edit, or delete events. All processing happens within Google’s infrastructure — no data is sent to external servers.

Can I export shared calendars?

Yes. Any calendar visible in your Google Calendar (including shared team calendars) can be selected for export.

What about Google Workspace admin calendars?

The add-on reads calendars available to the signed-in user. If your Workspace admin has shared resource calendars with you, they’ll appear in the picker.
