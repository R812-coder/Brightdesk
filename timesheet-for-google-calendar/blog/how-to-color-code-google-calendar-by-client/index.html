Why color coding changes everything

Open your Google Calendar right now. If all your events are the same default blue, you can’t tell at a glance how your time is distributed across clients. Is Client A getting more hours than Client B? Did you actually work on that proposal this week? How much of your time is non-billable?

Color coding answers all of these questions instantly. One glance at a color-coded week tells you exactly where your time went — no spreadsheet required. And when it is time to create a timesheet, those colors become automatic project categories.

How to assign colors to events

There are two ways to color an event in Google Calendar:

When creating a new event

  1. Click on a time slot to create a new event
  2. Click More options (or the pencil icon to expand the event editor)
  3. Find the colored circle next to your calendar name (usually near the bottom)
  4. Click it to open the color palette — 11 colors plus “Calendar color” (default)
  5. Pick your client’s color
  6. Save the event

For an existing event

  1. Click the event in your calendar
  2. Click the pencil icon to edit
  3. Find the color selector and change it
  4. Save
Keyboard shortcut: In the event editor, the color picker is a single click. It takes less than 2 seconds. That’s the total extra effort per event. Over a week of 20 events, that’s under a minute of work that saves 20+ minutes of billing reconstruction later.

Build your color system

The best color system is one you can remember without checking a reference. Here’s a template that works for most freelancers:

For 2-3 clients

  • Tomato (red) — Primary client (most hours)
  • Basil (green) — Secondary client
  • Peacock (blue) — Third client
  • No color (default) — Internal / non-billable

For 4-6 clients

  • Tomato (red) — Client A
  • Basil (green) — Client B
  • Peacock (blue) — Client C
  • Banana (yellow) — Client D
  • Tangerine (orange) — Client E
  • Grape (purple) — Client F
  • Graphite (gray) — Internal / admin

By work type (alternative approach)

  • Tomato — Client meetings
  • Basil — Deep work / deliverables
  • Peacock — Admin / invoicing
  • Banana — Learning / professional development
  • Graphite — Personal / breaks
Pick one system and stick with it. Don’t switch which color means which client mid-project. Consistency is what makes color coding useful for billing. Write your system on a sticky note until it becomes muscle memory.

What if I have more than 11 clients?

11 colors is enough for most freelancers, but if you work with more clients simultaneously, use keyword rules as a supplement. Color your top 5-6 active clients. For the rest, include the client name in the event title and set up keyword matching.

For example, if you don’t have a color for Client G, name events “ClientG — Website Review” and set a keyword rule: title contains “ClientG” → Client G at $100/hr. The keyword rule catches these events even without a color.

4 habits to make it stick

1. Color the event when you create it

Don’t batch-color at the end of the week. By then you won’t remember which events were for which client. Color as you go.

2. Add events for unscheduled work

A 15-minute client phone call doesn’t appear in your calendar unless you add it. Make a quick event with the right color immediately after the call ends.

3. Use “no color” intentionally

Don’t just forget to color events. Make “no color” mean something: non-billable / internal. This way, any uncolored event is intentionally non-billable, and your timesheet correctly shows it as $0.

4. Review your colors on Friday

Spend 2 minutes at the end of each week scanning your calendar for events you forgot to color. Fix them while you still remember what they were for.
