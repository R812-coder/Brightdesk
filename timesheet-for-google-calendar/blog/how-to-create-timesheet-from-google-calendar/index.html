The problem: Calendar has the data, but no export

Google Calendar knows exactly what you did, when you did it, and how long it took. Every meeting, work session, and client call is logged with a start time, end time, and title. For freelancers and consultants billing hourly, this is a goldmine of time data.

The problem? Google Calendar’s only native export format is .ics — which is designed for transferring events between calendar apps, not for generating spreadsheets. There’s no built-in way to get a simple table of events with hours and billing amounts.

This gap forces thousands of freelancers to manually re-enter their hours into separate time tracking tools like Harvest ($144/year) or Toggl ($108/year) — essentially duplicating data that already exists in their calendar.

There are two ways to solve this. Let’s start with the manual method, then cover the fast way.

Method 1: Manual copy-paste (free, slow)

You can create a timesheet by hand in Google Sheets. Here’s the process:

  1. Create a Google Sheet with columns: Date, Start Time, End Time, Duration, Project, Description
  2. Open Google Calendar in a separate tab
  3. Go through each day of your billing period
  4. For each event, type the date, start time, end time, event name, and project into the spreadsheet
  5. Calculate duration with a formula like =(C2-B2)*24 for each row
  6. Add a rate column and multiply duration × rate for each row
  7. Sum everything at the bottom
Why this method breaks down quickly: This works for a week with 10 events. It becomes painful for a month with 60+ events. And it completely falls apart when you have recurring events (weekly standups show as one event in Calendar but should be 4-5 separate timesheet rows), events spanning midnight, or multiple calendars. You’ll also need to handle timezone conversions manually if you work across time zones.

Method 2: One-click with an add-on (free, fast)

The faster approach is to use a Google Sheets add-on that reads your calendar events automatically and generates a formatted timesheet. Timesheet for Google Calendar does exactly this — it reads your events (read-only, it never modifies your calendar), categorizes them by project using the colors you already assign in Calendar, and generates a complete timesheet with hours, rates, and billing amounts.

Here’s how to set it up:

Step 1: Install the add-on

  1. Open any Google Sheet
  2. Go to Extensions → Add-ons → Get add-ons
  3. Search for “Timesheet for Google Calendar”
  4. Click Install and grant the requested permissions (read-only calendar access + write to current spreadsheet)

Step 2: Set up color-based categorization

This is the key insight that makes this approach work: you probably already color-code your Google Calendar events by project. If not, start now — it takes seconds per event and it’s the fastest way to categorize your time.

In Google Calendar, right-click any event and pick a color. Use a consistent system:

  • Tomato (red) → Client A
  • Basil (green) → Client B
  • Peacock (blue) → Internal work
  • Banana (yellow) → Client C

In the add-on sidebar, go to the Mappings tab. You’ll see all 11 Google Calendar colors listed. For each color you use, type the project name and hourly rate. Click Save Mappings.

Don’t color every event? That’s fine. Use keyword rules as a backup. In the Mappings tab, add rules like: title contains “Acme” → Client A at $150/hr. The add-on checks color first, then keywords, so both systems work together.

Step 3: Generate your timesheet

  1. Go to the Generate tab in the sidebar
  2. Select which calendars to include (checkboxes)
  3. Pick a date range: This Week, Last Week, This Month, Last Month, or Custom
  4. Click Preview Stats to see a summary before generating (total events, hours, billing)
  5. Click Generate Timesheet

The add-on creates three tabs in your spreadsheet:

  • Timesheet — Every event as a row with Date, Day, Start, End, Event name, Hours, Project, Rate, Amount, and Notes
  • Summary — Total hours and billing per project, ready for invoicing
  • Review — Flags potential billing errors: uncategorized events, overlapping meetings, untitled events, and suspiciously short events
One-click refresh for future billing cycles: After your first setup, you don’t need to reconfigure anything. Just go to Extensions → Timesheet for Google Calendar → Refresh Timesheet and it regenerates with your saved settings. True one-click, no sidebar needed.

Tips for accurate billing

1. Color events as you create them

Don’t wait until the end of the week to color-code. When you create a new event, pick the color immediately. It takes one extra click and saves you from the “what project was this for?” guessing game later.

2. Use the Review tab

Before sending an invoice, check the Review tab for uncategorized events. These are events the add-on couldn’t match to any project — they need your attention. Either add a color/keyword mapping for them, or decide they’re not billable.

3. Set up keyword rules for recurring patterns

If you have events like “Acme standup” or “[ClientB] design review” that follow a naming pattern, add keyword rules. The title text “Acme” will auto-match even if you forget to color the event.

4. Choose the right rounding

Standard billing practice is quarter-hour (15-minute) rounding. Lawyers often use sixth-hour (6-minute / 0.1 hour) increments. Set this in Settings before generating — it applies to all events.

5. Generate at the end of each billing period

Make it a habit: last day of the week/month → open your timesheet spreadsheet → Extensions → Refresh Timesheet → review → invoice. The whole process takes under a minute.

Frequently asked questions

Does the add-on modify my calendar events?

No. It uses read-only access (calendar.readonly) and can never create, edit, or delete your events. It only reads event data to generate the timesheet.

Does my data leave Google’s servers?

No. All processing happens within Google Apps Script on Google’s infrastructure. No data is transmitted to external servers, and the developer has no access to your calendar or spreadsheet data.

What’s free vs. paid?

Free tier: 1 calendar, 2-week date range, 3 color mappings, 3 keyword rules, Timesheet tab. Pro ($39/year): unlimited calendars and date ranges, all 11 color mappings, unlimited keyword rules, Summary + Review tabs, description parsing, no branding footer.

Can I use it with shared/team calendars?

Yes. Any calendar visible in your Google Calendar (including shared calendars from coworkers) can be selected in the sidebar. Pro users can pull from multiple calendars simultaneously.
