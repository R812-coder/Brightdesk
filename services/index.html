An example

Center for Radical Calling, Google Apps Script

103 people each needed their own assessment report: an email with their radar chart in the body and the right one of five PDFs attached. The mail merge tool they planned to use couldn't attach a different file per person.

The send was built as a script in their own spreadsheet. It checked every row before sending, ran in batches that survive Apps Script's time limit, and wrote each send back to the sheet so a re-run could never send twice.

103 sent, every one confirmed in the Sent folder, none sent twice.
