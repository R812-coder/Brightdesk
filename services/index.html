What this looks like in practice

One example, start to finish.

103 personalized assessment reports, sent in one run

Center for Radical Calling · Google Apps Script

The client needed to send individual assessment reports to 103 people. Each email had to carry that person's own radar chart embedded in the body and the correct archetype PDF attached — five possible PDFs, matched per recipient. The original plan was a third-party mail merge tool, which couldn't do per-recipient attachments.

I built it as a script inside their own spreadsheet instead. Filenames were parsed and cross-referenced against emails, data was validated before a single message went out, and the send ran in resumable batches so Apps Script's six-minute execution limit couldn't strand it halfway. Every send was written back to the sheet only after it succeeded, so a re-run could never double-send. One recipient had taken the assessment twice and needed two separate emails with two different charts — handled with a per-row override.

The client ran the final send himself from his own account, with a verification step that checked every message against his Sent folder afterward.
